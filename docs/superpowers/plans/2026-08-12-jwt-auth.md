# JWT Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace client-facing Better Auth session cookies with JWT access tokens (15 min) plus httpOnly refresh cookies (7 days), verified via JWKS, with `{ user, accessToken }` in sign-in responses.

**Architecture:** Add Better Auth `jwt()` plugin; after each sign-in path, `AuthService` extracts the internal BA session token, calls `auth.api.getToken`, sets `auth_token` + `auth_refresh` cookies via `AuthJwtUtils`, strips `better-auth.session_token`, and returns `{ user, accessToken }`. Protected controllers use `JwtAuthGuard` + `@JwtUser()` instead of `@Session()`.

**Tech Stack:** NestJS 11, `@thallesp/nestjs-better-auth`, `better-auth` ^1.6.26, `jose` ^6, bun, Jest, Next.js dashboard

**Spec:** [`docs/superpowers/specs/2026-08-12-jwt-auth-design.md`](../specs/2026-08-12-jwt-auth-design.md)

## Global Constraints

- JWT-only at the edge; Better Auth sessions internal only (Stripe, OAuth, refresh backing).
- Access JWT TTL: **15 minutes**; refresh cookie TTL: **7 days**.
- Access transport: `auth_token` httpOnly cookie **and** `Authorization: Bearer` header.
- Refresh transport: `auth_refresh` httpOnly cookie only (never in JSON body).
- Strip `better-auth.session_token` / `__Secure-better-auth.session_token` from all client-facing `Set-Cookie`.
- Do **not** add Better Auth Bearer plugin.
- JWKS path: `{baseUrl}/auth-service/jwks` (Better Auth default with `basePath: '/auth-service'`).
- Nest wrappers under `/auth`; BA callbacks under `/auth-service`.
- Specs under `__tests__/`; static helpers on `AuthJwtUtils` / `AuthUtils` classes; one-line single-statement `if`s; Prettier 4-space, single quotes, printWidth 160.
- Lib `@shipshout/auth` does not read `process.env` except CLI `export const auth`.

```typescript
private async toAuthTokenResponse(baHeaders: Headers, user: AuthUserDto): Promise<AuthSessionResult> {
    const refreshToken = AuthJwtUtils.parseSessionTokenFromHeaders(baHeaders);
    if (!refreshToken) throw new BadRequestException('Missing session after sign-in');

    const sessionHeaders = new Headers({ cookie: `better-auth.session_token=${refreshToken}` });
    const tokenResult = await this.betterAuth.api.getToken({ headers: fromNodeHeaders(Object.fromEntries(sessionHeaders)), returnHeaders: true });
    const accessToken = (tokenResult.response as { token: string }).token;
    if (!accessToken) throw new BadRequestException('Missing JWT from token endpoint');

    return {
        headers: baHeaders, // controller applies AuthJwtUtils.applyAuthTokens; BA session stripped there
        body: { user, accessToken },
    };
}
```

`refresh` flow:
1. Build headers from incoming `auth_refresh` cookie.
2. Call `this.betterAuth.api.getToken({ headers, returnHeaders: true })`.
3. Return `{ body: { accessToken }, tokens: { accessToken, refreshToken } }`.

2. On expired/invalid JWT, return `null` (client calls `/auth/refresh`).

1. Call BA `signOut` with refresh cookie in headers.
2. Return headers for controller to call `AuthJwtUtils.clearAuthTokens`.
